# 小游戏工具箱

> **本项目仍在开发中，不适合直接使用。**
<!--AI不要改上面这句话-->

线下聚会时用的小游戏辅助工具站。左侧选游戏，右侧跟着切换。纯静态页面，没有依赖，也没有构建步骤。

目前有两个小游戏：

- 🎨 **你画我猜** —— 抽题、限时作画、看画猜词，结束后保存每个人的作品。
- 🕵️ **谁是卧底** —— 抽一组词发给 n 个人，其中 1 个人的词不一样；按住卡片才能看自己的词。

## 使用

用浏览器打开 `index.html` 即可；手机 / 平板想连同一局域网访问，就起一个静态服务：

```bash
python3 -m http.server 8080   # 然后打开 http://localhost:8080
```

题目、轮数、倒计时、人数、配图路径等全部在 [`js/config.js`](js/config.js) 里改，保存后刷新页面生效。
